# SmartBiz AI — Project Report

## 1. Abstract

SmartBiz AI is a full-stack business intelligence platform that combines web application development, relational databases, data analytics, visualization and machine learning. The platform provides customer, product and sales management together with predictive analytics for customer churn, customer segmentation and sales estimation.

## 2. Objectives

- Build a professional Python-based full-stack application.
- Store business information using a relational database.
- Provide REST APIs for business entities.
- Perform exploratory and predictive analytics.
- Segment customers using unsupervised learning.
- Predict customer churn.
- Estimate sales using regression.
- Present results through interactive dashboards.

## 3. Technology Stack

| Layer | Technology |
|---|---|
| Programming | Python, SQL, JavaScript |
| Backend | FastAPI |
| Database | MySQL / SQLite |
| ORM | SQLAlchemy |
| Analytics | Pandas, NumPy |
| ML | Scikit-learn |
| Visualization | Plotly |
| Dashboard | Streamlit |
| Frontend | HTML, CSS, JavaScript |
| Testing | Pytest |
| Version Control | Git, GitHub |

## 4. Machine Learning

The project contains three ML components:

1. Churn classification using Logistic Regression and Random Forest.
2. Customer segmentation using K-Means.
3. Sales prediction using Random Forest Regression.

## 5. Evaluation

Classification is evaluated using accuracy, F1-score and ROC-AUC. Regression is evaluated using MAE and R². Clustering is interpreted through customer-value and engagement profiles.
