# Machine Learning Pipeline

1. Generate or collect business records.
2. Validate numerical and categorical fields.
3. Engineer customer-value and engagement features.
4. Split training/test data.
5. Train classification and regression models.
6. Scale features for clustering.
7. Evaluate using accuracy, F1, ROC-AUC, MAE and R².
8. Persist models with Joblib.
9. Expose predictions through FastAPI.
10. Visualize insights in Streamlit.
